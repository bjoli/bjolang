* Bjolang Prelude

The prelude contains the default environment available to all Bjolang programs. These procedures are automatically in scope.

** Core Values and Constants
- ~true~ : Boolean true
- ~false~ : Boolean false

** I/O
- ~(display x)~ : Prints ~x~ to standard output without a newline.
- ~(displayln x)~ : Prints ~x~ to standard output with a newline.
- ~(print x)~ : Generic print utilizing the ~->str~ trait.
- ~(println x)~ : Generic println utilizing the ~->str~ trait.
- ~(read-line)~ : Reads a line of text from standard input.
- ~(newline)~ : Prints a newline character.

** Math Operators
Standard polymorphic math operators (deferred to C# for resolution):
- ~(+ a b)~
- ~(- a b)~
- ~(* a b)~
- ~(/ a b)~
- ~(% a b)~

** Comparison
- ~(= a b)~
- ~(< a b)~
- ~(> a b)~
- ~(<= a b)~
- ~(>= a b)~
- ~(eq? a b)~ : Pointer/Reference equality (structural for value types).
- ~(equal? a b)~ : Structural/Generic equality.

** String Operations
- ~(string-append a b)~ : Concatenates strings ~a~ and ~b~.
- ~(string-length s)~ : Returns the length of string ~s~.

** Conversions
- ~(byte->string b)~
- ~(int->string i)~ (also ~number->string~)
- ~(long->string l)~
- ~(double->string d)~
- ~(string->int s)~
- ~(string->double s)~
- ~(keyword->string kw)~ : Returns the string name of a keyword.
- ~(string->keyword s)~ : Interns a string as a ~Keyword~.
- ~(symbol->string sym)~ : Returns the string name of a symbol.
- ~(string->symbol s)~ : Interns a string as a ~Symbol~.

** Keywords and Symbols
Keywords (~:foo~ or ~#:foo~) and quoted symbols (~'foo~) are interned first-class types.
- ~(keyword? x)~ : Returns true if ~x~ is a ~Keyword~.
- ~(symbol? x)~ : Returns true if ~x~ is a ~Symbol~.
- Keywords and symbols can be compared with ~(eq? a b)~ for $O(1)$ reference equality and used as map keys.

** Lists (~SchemeList~)
Built-in functional linked lists.
- ~(Cons head tail)~, ~(cons head tail)~ : Constructs a list.
- ~(Nil)~, ~(list-empty)~ : Returns an empty list.
- ~(list-head lst)~ : Returns the first element.
- ~(list-tail lst)~ : Returns the rest of the list.
- ~(list-empty? lst)~ : Returns true if the list is empty.
- ~(list-length lst)~, ~(list-count lst)~ : Returns the number of elements.
- ~(list-reverse lst)~ : Reverses the list.
- ~(list-map f lst)~ : Maps function ~f~ over the list.
- ~(list-filter f lst)~ : Filters elements satisfying ~f~.
- ~(list-foldl f init lst)~ : Left fold; ~f~ receives ~(acc item)~.
- ~(list-foldr f init lst)~ : Right fold; ~f~ receives ~(item acc)~.
- ~(list-for-each f lst)~ : Applies ~f~ to each element for side effects.
- ~(list-ref lst index)~ : Gets the element at ~index~.

** Vectors (~Vec~ / ~RrbList~)
Persistent immutable vectors.
- ~(vec-empty)~ : Returns an empty vector.
- ~(vec-get vec index)~ : Gets the element at ~index~.
- ~(vec-set vec index value)~ : Returns a new vector with ~value~ at ~index~.
- ~(vec-add vec item)~ : Returns a new vector with ~item~ appended.
- ~(vec-insert vec index item)~ : Returns a new vector with ~item~ inserted at ~index~.
- ~(vec-remove-at vec index)~ : Returns a new vector with the element at ~index~ removed.
- ~(vec-pop vec)~ : Returns a new vector with the last element removed.
- ~(vec-pop-first vec)~ : Returns a new vector with the first element removed.
- ~(vec-slice vec start count)~ : Returns a sub-vector.
- ~(vec-merge vec other)~ : Concatenates two vectors.
- ~(vec-merge/pure vec other)~ : Concatenates two vectors (pure).
- ~(vec-split vec index)~ : Splits the vector into two vectors at ~index~.
- ~(vec-map f vec)~ : Maps ~f~ over the vector.
- ~(vec-filter f vec)~ : Filters the vector.
- ~(vec-fold f init vec)~ : Left fold; ~f~ receives ~(acc item)~.
- ~(vec-reduce f vec)~ : Reduces the vector.
- ~(vec-for-each f vec)~ : Applies ~f~ for side effects.
- ~(vec-for-each/range f vec start count)~ : Applies ~f~ over a range.
- ~(vec-iter f vec)~ : Iterates with early exit (returns true if all elements matched).
- ~(vec-count vec)~ : Returns the size of the vector.
- ~(vec-contains vec item)~ : Checks if ~item~ is in the vector.
- ~(vec-compact vec)~ : Compacts the vector's internal structure.

** Vector Builders
Mutable builders for efficiently constructing vectors.
- ~(vecbuilder-empty)~ : Creates an empty builder.
- ~(vec->vecbuilder vec)~ : Creates a builder from a vector.
- ~(vecbuilder-add! builder item)~ : Mutates the builder by appending ~item~.
- ~(vecbuilder-set! builder index item)~ : Mutates the builder by setting ~item~ at ~index~.
- ~(vecbuilder-get builder index)~ : Gets the element at ~index~.
- ~(vecbuilder-count builder)~ : Returns the size.
- ~(vecbuilder->vec builder)~ : Freezes the builder into an immutable vector.

** Maps (~Map~)
High-performance immutable CHAMP (Compressed Hash-Array Mapped Prefix-tree) maps.
- ~(map-empty)~ : Returns an empty map.
- ~(map-ref map key)~ : Returns the value for ~key~; throws if not found.
- ~(map-get map key)~ : Returns the value for ~key~; throws if not found.
- ~(map-get-or map key default-val)~ : Returns the value for ~key~, or ~default-val~ if not found.
- ~(map-try-get map key)~ : Returns ~(Some val)~ if found, or ~None~ if not.
- ~(map-set map key value)~ : Returns a new map with ~key~ mapped to ~value~.
- ~(map-add map key value)~ : Returns a new map with ~key~ mapped to ~value~.
- ~(map-remove map key)~ : Returns a new map with ~key~ removed.
- ~(map-contains? map key)~ : Returns true if ~key~ is in ~map~.
- ~(map-has-key? map key)~ : Returns true if ~key~ is in ~map~.
- ~(map-count map)~ : Returns the number of key-value pairs in ~map~.
- ~(map-empty? map)~ : Returns true if ~map~ is empty.
- ~(map-clear map)~ : Returns an empty map.
- ~(map-keys map)~ : Returns a lazy sequence (~Seq~) of the map's keys.
- ~(map-values map)~ : Returns a lazy sequence (~Seq~) of the map's values.
- ~(map-merge map other)~ : Merges two maps, with entries in ~other~ taking precedence.
- ~(map-merge-with f map other)~ : Merges two maps using resolver function ~(f key val1 val2)~ for duplicate keys.
- ~(map-for-each f map)~ : Applies ~(f key value)~ to each entry for side effects.
- ~(map-iter f map)~ : Iterates with early exit; ~f~ receives ~(key value)~ and returns a boolean.
- ~(map-fold f init map)~ : Folds over the map; ~f~ receives ~(acc key value)~.
- ~(map-filter f map)~ : Returns a new map containing only entries where ~(f key value)~ is true.
- ~(map-map f map)~ : Returns a new map with values transformed by ~(f key value)~.
- ~(list->map lst)~ : Constructs a map from a list of ~(key . val)~ pairs/tuples.
- ~(map->list map)~ : Converts the map to a list of pairs/tuples.
- ~(vec->map vec)~ : Constructs a map from a vector of pairs/tuples.
- ~(map->vec map)~ : Converts the map to a vector of pairs/tuples.
- ~(seq->map seq)~ : Constructs a map from a sequence of pairs/tuples.
- ~(map->seq map)~ : Converts the map to a sequence of pairs/tuples.

** Options (~Option~)
Optional value type representing presence (~Some~) or absence (~None~).
- ~(Some val)~ : Wraps ~val~ in an option.
- ~None~ : Represents no value.
- ~(some? opt)~ : Returns true if ~opt~ is ~Some~.
- ~(none? opt)~ : Returns true if ~opt~ is ~None~.
- ~(option-get opt)~ : Returns the unwrapped value; throws if ~None~.
- ~(option-get-or opt default-val)~ : Returns the unwrapped value, or ~default-val~ if ~None~.

** Sequences (~Seq~)
Lazy, demand-driven sequences.
- ~(seq-empty)~ : Returns an empty sequence.
- ~(seq-empty? s)~ : Returns true if the sequence is empty.
- ~(seq-head s)~ : Returns the first element of the sequence.
- ~(seq-tail s)~ : Returns the rest of the sequence.
- ~(seq-map f s)~ : Lazily maps ~f~ over the sequence.
- ~(seq-filter f s)~ : Lazily filters elements satisfying ~f~.
- ~(seq-fold f init s)~ : Folds over the sequence; ~f~ receives ~(acc item)~.
- ~(seq-unfold generator state)~ : Produces a sequence from ~state~ and a ~generator~ function returning ~(Some (Tuple next-item next-state))~ or ~None~.
- ~(seq-take s n)~ : Takes the first ~n~ elements lazily.
- ~(seq-skip s n)~ : Skips the first ~n~ elements lazily.
- ~(seq-append s1 s2)~ : Lazily concatenates two sequences.
- ~(seq-for-each f s)~ : Applies ~f~ to each element for side effects.
- ~(seq-count s)~ : Consumes the sequence and returns the count.
- ~(seq-range start count)~ : Returns a lazy integer range sequence.
- ~(list->seq lst)~ : Converts a list to a lazy sequence.
- ~(seq->list s)~ : Consumes a sequence into a list.
- ~(vec->seq vec)~ : Converts a vector to a lazy sequence.
- ~(seq->vec s)~ : Consumes a sequence into a vector.

** Iterators
Standard iterator protocol for collections.
- ~(iterate col)~ : Returns an iterator for the collection.
- ~(done? iter)~ : Returns true if the iterator is exhausted.
- ~(current iter)~ : Returns the current element.
- ~(next iter)~ : Advances the iterator.

** Traits
- ~->str~ : Trait for string representation with method ~(->str x)~. Implemented for ~string~, ~int~, ~double~, ~byte~, ~long~.
- ~Iterator~ : Trait for iterators.
- ~Iterable~ : Trait for iterable collections.
